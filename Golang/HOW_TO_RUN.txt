RAMIFY OS v11.0.7 - FINAL GO + LATEST FRONTEND
================================================

PACKAGED WINDOWS RELEASE - ONE CLICK
------------------------------------
The packaged release ZIP includes generated binaries that are intentionally
not committed to GitHub.

1. Extract the packaged release ZIP completely.
2. Open the bin folder.
3. Double-click RAMIFY.exe.

RAMIFY selects a free 127.0.0.1 port and opens the Shop automatically.
No Python, FastAPI or Uvicorn installation is required.

GITHUB SOURCE CHECKOUT
----------------------
The GitHub repository does not contain bin/RAMIFY.exe because /bin and *.exe
are generated build artefacts and are ignored.

From the repository root:

  cd Golang
  go test ./...
  go vet ./...
  go run ./cmd/ramify

LOCAL STATE
-----------
Receipts, action history, basket/orders/requisitions and edited/custom agents
are kept in runtime_data so they survive closing and reopening the application.
To start with a clean local demo, close RAMIFY and clear the contents of
runtime_data. Do not remove demo_runtime_seed.

OPTIONAL LIVE LOCAL AI
----------------------
RAMIFY works without a model. To enable local free-form interpretation and
receipt explanation:

  ollama pull llama3.1
  ollama serve

The Go application talks to Ollama on http://127.0.0.1:11434 by default.
The LLM never decides trust or transaction authority. If Ollama is unavailable,
RAMIFY safely falls back to the deterministic catalogue matcher.

Optional environment variables:
  RAMIFY_LOCAL_MODEL=llama3.1
  RAMIFY_OLLAMA_BASE_URL=http://127.0.0.1:11434
  RAMIFY_LOCAL_MODEL_TIMEOUT=5
  RAMIFY_DISABLE_AGENT=1
  RAMIFY_DATA_DIR=<custom local state folder>

SOURCE DEVELOPMENT
------------------
Requires Go 1.23+. Run these commands from the Golang directory:

  go test ./...
  go vet ./...
  go run ./cmd/ramify

Start without opening a browser:
  go run ./cmd/ramify -no-browser

Force port 8000:
  go run ./cmd/ramify -no-browser -port 8000

STANDALONE RECEIPT VERIFIER
---------------------------
Packaged Windows release:
  bin\RAMIFY-Verify.exe receipt.json

From GitHub source:
  go run ./cmd/verify receipt.json

Packaged Linux/macOS release builds are generated separately and are not
committed to this source repository.
