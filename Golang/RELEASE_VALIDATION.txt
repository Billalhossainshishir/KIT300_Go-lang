SIGNER LIFECYCLE
----------------
PASS  Receipt private signer is generated/stored in machine-local runtime state.
PASS  No private receipt-signing seed is distributed in the Go repository.
PASS  Existing signed history + missing/corrupt signer refuses silent identity rotation.
PASS  Explicit signer rotation retains previous public keys for historical verification.
PASS  Receipt verification reports the signer fingerprint that verified the record.
PASS  /healthz, receipt verification and Proof Pack expose consistent current signer fingerprint.
